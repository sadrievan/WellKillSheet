# Лист глушения скважины — Android MVP

Приложение на Kotlin + Jetpack Compose для Android. Оно принимает исходные параметры, показывает расчётные значения и формирует двухстраничный PDF в папке «Документы».

## Сборка
1. Установите Android Studio (современную версию) и Android SDK 35.
2. Откройте папку `WellKillSheet` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Для тестового APK выберите **Build → Build APK(s)**.
5. APK обычно появляется в `app/build/outputs/apk/debug/app-debug.apk`.

## Важно о формулах
Поля и обозначения взяты из предоставленного образца «Лист глушения». Приложение использует плотность в кг/м³ (СИ), давление в МПа, длину в метрах, объём в литрах (литры сохранены как в образце).

Перед промышленным использованием необходимо проверить все формулы и соответствие конкретной редакции формы ответственным специалистом предприятия. В частности, объёмные категории D/F/G и выбор насоса для расчёта E должны быть подтверждены по рабочей методике. Это MVP для проверки структуры и ввода, не сертифицированный инженерный расчётный инструмент.

## Что уже есть
- Ввод даты, ФИО и объекта.
- Поля давления, плотности, глубины, насосов, объёмов и данных о притоке.
- Автоматический пересчёт результатов при изменении полей.
- PDF на 2 страницы, A4, пригодный для сохранения/печати.
- Работает без интернет-подключения.

## Что нужно согласовать для следующей версии
- Точные определения BT/TBT/UBT и геометрические формулы для удельных объёмов.
- Какой насос используется в расчёте числа ходов и начального/конечного давления.
- Нужен ли точный графический клон исходного бланка.
- Правила округления, валидации, пределы допустимых значений и нормативная ссылка.


## Облачная сборка APK без Android Studio
В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`.
После загрузки исходников в репозиторий GitHub:
1. Откройте вкладку **Actions**.
2. Выберите **Build Android APK**.
3. Нажмите **Run workflow** (или дождитесь автоматического запуска после push).
4. Откройте завершившийся запуск и скачайте артефакт **WellKillSheet-debug-apk**.
5. Распакуйте скачанный ZIP — внутри будет `app-debug.apk`.

Для частного репозитория применяются ограничения бесплатного плана GitHub Actions; публичные репозитории используют стандартные hosted runners бесплатно. Не размещайте в публичном репозитории конфиденциальные данные или ключи.
